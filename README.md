# DL1 Spawner

# Item Spawner
allows you to spawn any item via id and quantity, item id's can be dumped at any time by pressing VK_END, results are saved in game directory as dumped_items.txt

# Item Duper
hooks drop inventory item to not delete the dropped item from the players inventory, therefore allowing you to drop items as many times as you want without losing them
effectively duplicating them

current information on the valid id's can be found in dumped_items.txt, a copy included in this project for convenience
